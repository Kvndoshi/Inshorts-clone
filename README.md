## Inshorts Clone

This is a simple clone of the Inshorts app. It displays news in short (a concise summary), with a "Read More" option to open the full article.

### Features
- Shows short news summaries similar to Inshorts
- "Read More" button to open the full news in browser
- A Switch button to toggle focus to Bitcoin-related news. You can add more categories similarly to suit your preferences.
